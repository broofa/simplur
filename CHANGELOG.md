# Changelog

All notable changes to this project are documented in this file.

## [4.1.0] - 2026-02-18

### Added

- Support for passing pluralization tokens as template expressions.

### Changed

- Updated test coverage and build scripts.
- Refreshed README and package metadata.

## [4.0.0] - 2024-04-17

### Changed

- Breaking change: migrated the package to ESM and TypeScript.

## [3.0.1] - 2021-06-02

### Changed

- Repository split from `broofa/BroofaJS` into a dedicated `simplur` repository.
